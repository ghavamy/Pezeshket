# Expanded Persian healthcare portal starter
An original, editable starter—not Pezeshket's proprietary source code or exact assets.

Includes homepage sections and interactive carousels, plus demo internal routes:
- `/doctors`
- `/specialties`
- `/articles`
- `/about`
- `/contact`

Run `npm install && npm start`, then open http://localhost:3000.
Carousel controls are functional. Replace demo text/data/images and connect your own API.
